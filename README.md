# U.S. Border Crossing Entry Analysis (1996 - 2025) 📊🗺️

## 📌 Project Overview
An interactive Data Science project analyzing 30 years of U.S. border crossing data. This project transforms raw government data into actionable insights regarding logistics, port utilization, and transport trends using Power BI and DAX.

## 🚀 Key Features
- **Dynamic KPIs:** Real-time tracking of Total Crossings, Active Ports, and Peak Year traffic.
- **Geospatial Mapping:** Interactive bubble maps pinpointing high-traffic entry points.
- **Advanced DAX:** Custom measures for Month-over-Month (MoM) growth and Category Grouping (Commercial, Private, Public).
- **Time Intelligence:** Comprehensive analysis of crossing trends from 1996 to the projected 2025 data.

## 🛠️ Tech Stack
- **Tool:** Power BI Desktop
- **Language:** DAX (Data Analysis Expressions)
- **Data Source:** [Data.gov / Bureau of Transportation Statistics](https://catalog.data.gov/dataset/border-crossing-entry-data)
- **ETL:** Power Query

## 📈 Insights Preview
- **Peak Volume:** The year **2000** remains the historical peak for border entries.
- **Regional Dominance:** The **US-Mexico border** handles ~65% of total traffic, with Texas being the busiest state.
- **Modal Shift:** Commercial traffic shows higher resilience compared to passenger travel over the last decade.
